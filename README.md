Инструкция 
Шаг 1- Установить библиатеку Allure командой  pip install allure-pytest
Шаг 2 - Запустить тесты с параметром для сбора результатов Allure комндой - pytest --alluredir=allure-results - сформируется папка с результатами теста
Шаг 3- Запустить сформированный отчет командой - allure serve allure-result - откроется  в браузер с отчетом
